# Katrin & Vicentiu — Wedding Invitation Portal

React + Vite + **Motion (Framer Motion)**. Romanian, German and English.

**The experience:** a luxury envelope (gold foil, silk ribbon, wax seal with olive sprigs, three stamps, Par Avion label) →
break the seal (it cracks, splits, wax shards + gold sparks) → a summer gust blows the flap open → the forest-green gatefold
card rises and pops out → its doors swing open in a burst of gold → the invitation: names in gold foil, two champagne flutes
(etched K and V) that clink, the date, and a map linking Deutschland, România and Nederland → RSVP & story button.

## Run locally

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # static site in dist/ — upload anywhere (Netlify, Vercel, GitHub Pages…)
npm run preview   # preview the production build
npm run build:single   # ONE self-contained .html in dist-single/ (opens with a double-click)
```

## Where to edit things

| What | File |
|---|---|
| Names, date, **RSVP link**, venue, map points & route | `src/config/wedding.js` |
| All wording, per language (RO / DE / EN) | `src/i18n/translations.js` |
| Colours, fonts, spacing | `src/styles/tokens.css` |

Placeholder copy starts with “Placeholder —” / “Text provizoriu —” / “Platzhalter —”, so you can search for it.

## Structure

```
src/
  App.jsx                    envelope ↔ invitation page transition
  config/wedding.js          wedding facts
  i18n/                      translations + LanguageProvider (persists choice, ?lang=ro|de|en)
  styles/                    tokens.css (design system), base.css
  components/
    landing/                 Landing, Envelope (3D layers + phase timeline), SealBreak
    invitation/              Invitation (gatefold card), ChampagneToast
    map/                     JourneyMap + europeShapes.js (generated by tools/build-map.mjs)
    effects/                 GoldBurst, Gust, GoldMotes
    ornaments/               WaxSeal, Stamp, Postmark, Branch — reusable SVG pieces
    ui/                      Atmosphere, LanguageSwitcher, RevealText
```

## Motion & accessibility

- Every animation runs on Motion; `MotionConfig reducedMotion="user"` plus a CSS media query respect the OS reduced-motion setting. Smooth scrolling (Lenis) is off for those users.
- You can open the envelope with the keyboard (Enter / Space). The language buttons expose `aria-pressed`, and the `<html lang>` attribute follows the selected language.
- Fonts (Cormorant Garamond, Jost) are bundled locally, so the site makes no external font requests.
